Data Flow
---------

1. Application Startup
   ┌─────────────────────────────────────────────┐
   │  Application Start                          │
   └─────────────────┬───────────────────────────┘
                     │
                     ▼
   ┌─────────────────────────────────────────────┐
   │  Load Config: AppConfig::from_env()         │
   │  • Reads environment variables              │
   │  • Falls back to defaults                   │
   └─────────────────┬───────────────────────────┘
                     │
                     ▼
   ┌─────────────────────────────────────────────┐
   │  Validate: config.validate()                │
   │  • Checks all validation rules              │
   │  • Returns ConfigError on failure           │
   └─────────────────┬───────────────────────────┘
                     │
                     ▼
   ┌─────────────────────────────────────────────┐
   │  Use Config Throughout Application          │
   │  • Initialize logger                        │
   │  • Open session                             │
   │  • Connect to Telegram                      │
   │  • Connect to Phoenix                       │
   │  • Configure update stream                  │
   └─────────────────────────────────────────────┘


2. Environment Variable Priority

   Environment Variables
          │
          ▼
   ┌─────────────────┐
   │  from_env()     │  → If var exists: Use it
   │                 │  → If not: Use default
   └─────────────────┘


3. Configuration Usage Pattern

   ┌──────────────────────────────────────────────┐
   │  main.rs                                     │
   │  ┌────────────────────────────────────────┐ │
   │  │ let config = AppConfig::from_env()     │ │
   │  │ config.validate()?                     │ │
   │  │                                        │ │
   │  │ // Use config                          │ │
   │  │ logger.init(config.log.level_filter()) │ │
   │  │ session.open(&config.session.file)     │ │
   │  │ phoenix.connect(&config.phoenix.url)   │ │
   │  │ timeout(config.telegram.auth_timeout())│ │
   │  └────────────────────────────────────────┘ │
   └──────────────────────────────────────────────┘
